# Release Test Notes - 0.6.1

Date: 2026-11-20

## Scope

RobStride parameter-read failure semantics and Python CLI param typing.

## Key Changes

- RobStride: rejected reads (type-17 status != 0) fail the pending
  `get_parameter` immediately with a distinct Protocol error and wake the
  waiter; remaining host-id candidates are short-circuited.
- Python CLI: read/write-param type inference aligned with Rust
  `registers.rs` (0x7026 u16, 0x702A/0x702C/0x702D u8).

## Required Local Checks

```bash
cargo fmt --all -- --check
cargo build -p motor_abi
cargo test -p motor_vendor_robstride
```

## Hardware Verification (RS06 arm, mcu-serial)

- Import default params over ws_gateway: 0x702C/0x702D/0x702E reads fail
  fast (~ms) with "read rejected by motor (status 0x01)", one log line per
  param per joint, rows skipped, import completes without the offline-abort
  modal; other 26 params read/write/store normally.
- Silent bus (motor powered off) still times out and reports offline.
