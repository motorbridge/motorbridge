# Release Test Notes - 0.5.4

Date: 2026-09-09

## Scope

This release restores generic controller behavior by removing the hard-coded
gripper zero-point gate from the RobStride and Damiao `enable_all` paths.
Application code remains responsible for identifying gripper motors and
performing any application-specific pre-enable safety checks.

## Key Changes

- `RobstrideController::enable_all` directly delegates to the common
  controller implementation without reading motor ID 7.
- `DamiaoController::enable_all` directly delegates to the common controller
  implementation without reading motor ID 7.
- No CAN position/register read is added to the generic batch-enable path.
- The version is bumped to `0.5.4` for the generalized behavior.

## Required Local Checks

```bash
cargo fmt --all -- --check
cargo clippy -p motor_vendor_robstride -p motor_vendor_damiao
cargo test -p motor_vendor_robstride -p motor_vendor_damiao
cargo build -p motor_abi
```
